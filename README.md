# توأمي الرقمي

نسخة رقمية منك تتعلم من كلامك واختياراتك واهتماماتك وطريقة تفكيرك، وتعيش معها في عالم افتراضي صغير.
تسألها: «وش تتوقع إني أختار؟» وتجاوبك بناءً على اللي تعلمته عنك.

**افتحه:** <https://rajaxdx.github.io/digital-twin/>

صفحة واحدة (`index.html`) بلا مكتبات ولا خطوة بناء. كل البيانات تنحفظ في متصفحك بس.
